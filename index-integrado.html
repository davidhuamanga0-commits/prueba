Configuración inicial de la tienda

1. Ejecuta el SQL de configuración en tu proyecto Supabase.
2. Crea tu cuenta en Authentication → Users y desactiva el registro público.
3. Publica este archivo en HTTPS.
4. Si tus datos estaban en un HTML descargado, abre la versión nueva en la misma ubicación del archivo anterior y pulsa Respaldar datos de este navegador. Luego entra a la página web con tu cuenta y sube ese respaldo JSON.

La contraseña local anterior debe configurarse también en tu cuenta de Supabase para usarla en varios equipos.
